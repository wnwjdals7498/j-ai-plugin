> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PMT 백로그 B5(Plane 호출 한도를 프로세스 사이에 공유), B6(최종 리뷰 잔여 결함 3건), B7(CI 보류 Minor 5건)을 PR 하나로 고친다.

**Architecture:** B6은 `ledger/flows.py`·`ledger/check.py`의 국소 수정이다. B5는 새 모듈 `ledger/ratelimit.py`에 잠금 파일 기반 공유 제한기를 두고, `PlaneClient`가 제한기를 주입받게 한 뒤 CLI만 공유 제한기를 쓴다. B7은 CI 스크립트·문서·설정 정리이고, Dockerfile을 바꾸는 항목은 이미지 TAG를 2로 올려 다시 빌드한다.

**Tech Stack:** Python 3.9 표준 라이브러리(`fcntl`, `json`, `hashlib`, `os`), unittest, bash, Docker, trivy·semgrep(검사 이미지)

**Spec:** 없음(백로그 항목 자체가 요구사항). 근거: PMT `forge-wiki-plugin` 백로그 B5·B6·B7, 1부 최종 리뷰 결과(I3, 잔여 3건), CI 최종 리뷰의 "병합 후 정리 권장" 분류. 이 계획의 판정은 controller 판단이다.

## Global Constraints

- 저장소 코드: 표준 라이브러리만, `from __future__ import annotations`, Python 3.9 호환, ruff line-length 120, mypy strict, 시험은 `unittest`.
- 민감값(IP, 접속 주소, 토큰, 계정)은 파일·커밋 메시지·보고서·상태 파일에 넣지 않는다. 토큰은 해시로만 쓴다.
- `main`은 보호돼 있다. 모든 변경은 브랜치 `fix-backlog-b5-b7`에서 하고 PR로 병합한다. push·Gitea 설정·러너 재생성은 controller만 한다.
- 커밋 이력 재작성·force push 금지. 커밋 메시지는 한국어, 접두어 `fix:`/`feat:`/`test:`/`chore:`/`docs:`.
- 검사 이미지 태그 단일 원천은 `ci/image/TAG`다. Task 5에서 `2`로 올린다. 워크플로 `container:`와 러너 라벨은 이 값과 같아야 한다(`tests/test_ci_workflow.py`, `tests/test_ci_runner.py`가 확인).
- 공유 제한기 값: 창 60초, 기본 분당 50회, 상태 폴더 우선순위 `FORGE_LEDGER_STATE_DIR` → `$XDG_STATE_HOME/forge-ledger` → `~/.local/state/forge-ledger`, 폴더 권한 0700, 파일 권한 0600, 파일 이름 `plane-rate-<bucket>.json`·`plane-rate-<bucket>.lock`, `bucket`은 `sha256(base_url_without_trailing_slash + "\n" + token)` hex 앞 16자.
- 공유 제한기를 쓸 수 없으면(`fcntl` 없음, 폴더 생성·쓰기 실패) 프로세스 안 제한기로 돌아가고 stderr에 `공유 호출 한도 파일을 쓸 수 없어 프로세스 안 제한만 씁니다`를 한 번 출력한다.

### Task 3: Plane 호출 한도를 프로세스 사이에 공유 (B5)

**Files:**

**Interfaces:**
- Produces (`ledger/ratelimit.py`):
  - `class RateLimiter(Protocol): def acquire(self) -> None: ...`
  - `class LocalRateLimiter`: `__init__(self, per_minute: int = 50, window: float = 60.0, clock: Callable[[], float] = time.monotonic, sleep: Callable[[float], None] = time.sleep)`, `acquire() -> None`(지금 `PlaneClient._wait_rate_limit`의 deque 동작을 옮김)
  - `class SharedRateLimiter`: `__init__(self, state_dir: Path, bucket: str, per_minute: int = 50, window: float = 60.0, clock: Callable[[], float] = time.time, sleep: Callable[[float], None] = time.sleep)`, `acquire() -> None`
  - `bucket_name(base_url: str, token: str) -> str`, `default_state_dir(env: Mapping[str, str]) -> Path`
  - `make_shared_limiter(base_url: str, token: str, env: Mapping[str, str], per_minute: int = 50, notify: Optional[Callable[[str], None]] = None) -> RateLimiter`
- `PlaneClient.__init__`에 키워드 인자 `limiter: Optional[RateLimiter] = None`을 추가한다. 없으면 기존 인자(`per_minute`, `clock`, `sleep`)로 `LocalRateLimiter`를 만든다. 기존 시험은 바꾸지 않고 통과해야 한다.
- `cli.py`는 `PlaneClient(settings, limiter=make_shared_limiter(settings.base_url, settings.token, effective_env))`로 만든다.

`SharedRateLimiter.acquire` 알고리즘(시그니처와 시험만으로 정해지지 않는 부분):
```text
반복:
  잠금 파일을 열고 fcntl.flock(LOCK_EX)
  상태 파일을 읽어 timestamps 목록을 얻는다(없음·빈 파일·JSON 오류·형식 오류 → 빈 목록)
  now = clock(); now - window 이하이거나 now + window 초과(시계 되돌림)인 값은 버린다
  len < per_minute → now를 붙이고 임시 파일에 쓴 뒤 os.replace로 바꿔 넣고(권한 0600) 잠금을 풀고 끝
  아니면 wait = window - (now - min(timestamps)) 을 계산하고 잠금을 푼 뒤 sleep(max(wait, 0.05)), 다시 반복
```
