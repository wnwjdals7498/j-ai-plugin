This folder holds frozen synthetic inputs and repeatable legacy measurements. It does not contain user project data, conversation text, credentials, or provider output. Fixture quality is not model-quality evidence.

`scenario-catalog.json` defines six cases with the same project goal and required criteria. The saved Phase2 full-plan baseline is the sole pre-existing measurement. A second comparable fixture was replayed through the unchanged Phase2 `validate_graph` and `render_docs` functions. Resume, parallel investigation, ambiguous clarification, and authorized retry/rework remain `not_comparable` because no matching Phase2 receipt or cost trace exists.

The partial-change replay uses the canonical graph fixture at `../baseline/canonical-planning-graph.json`, verifies its SHA-256, then changes only requirement `00000000-0000-4000-8000-000000000002` field `premise`. Its frozen patched input, rendered Markdown, graph JSON, and measurement manifest are stored here. The manifest records five observations, each with 3,983 UTF-8 input bytes, 4,441 output bytes, two legacy calls, zero detail/context/retry/rework/review calls, token usage unknown, and fixture-only quality. Per-observation timing and artifact hashes are in `phase2-partial-change-full-render.json`.

Run `.venv/Scripts/python.exe scripts/verify_phase3_local.py --preflight` to inspect operation dispatchability without executing a scenario. Run `.venv/Scripts/python.exe scripts/verify_phase3_local.py --capture-partial-legacy` only to reproduce the frozen Phase2 baseline.
