# Hosted client-local graph and document effects — 2026-10-02

`pmt.hosted_files.HostedFiles(profile, state_port, spool_root).execute(request)` provides the hosted client adapter for graph preview/apply/recovery and document prepare/publish/recovery. It does not open a local PMT business database. The client authorizes the active Host run and path locks before reading local files, uses the existing SourcePin and workspace mapping, and publishes through the no-replace guarded file publisher. Host records effect IDs, hashes, phase receipts and scoped document manifests; it never reads client workspace paths or claims that it verified document bytes (`host_document_verified=false`).

Graph apply uploads the exact candidate graph snapshot, updates the Host SourcePin pointer with compare-and-set, rebuilds the Host graph index, then completes the effect. The effect intent captures the Host-current before graph resource reference, source-pointer reference/revision/hash and immutable candidate/change hashes. F3 comparison reopens that Host-scoped before graph and old registered manifests, checks bytes and pins, rebuilds the prior index, and reruns the Core impact calculation with its trusted index override. Caller `complete`/`unknown` flags alone are not accepted. Unknown or mismatched impact is rejected.

Document rendering preserves the current manual prefix/suffix and refreshes their hashes while rejecting edits to generated segments. Partial rendering requires the exact F1 effect, original ChangeSet, preview and F3 result. The Host recomputation must match the submitted semantic impact fields. A current document target hash is checked before publication; interrupted detached originals and candidates remain in the workspace recovery set. Recovery compares the Host intent, SourcePin and actual old/candidate/recovery bytes before resuming. A newly created competing target or unrecognized bytes are retained and returned as conflict.

Actual local HTTPS tests cover F5-bound graph preview, graph apply and SourcePin/index publication, first document baseline and partial update, manual span preservation, generated edit rejection, recomputed F3 against an immutable before graph, graph recovery after candidate upload interruption and after original-target detach, document recovery after detach, and preservation of a user-created competing target. These use isolated Uvicorn/TLS fixtures, temporary SQLite databases and Git checkouts. They do not call an external model or represent a deployed Host.
