# 3단계 실행 범위 결정

2026-10-02 사용자 결정: **지금은 로컬 검증까지만 진행한다.**

- 상세계획의 F0~F15 기능을 구현하며, 작업자는 `gpt-6-luna` 네이티브 서브에이전트를 사용한다.
- Host는 격리된 로컬 실제 HTTP/HTTPS 프로세스와 두 클라이언트로 확인한다. 운영 Linux 서버·공개 주소 배포와 사용자 데이터 전환은 이번 실행에 포함하지 않는다.
- 직접 모델 API와 Claude 실서비스 전송 시험은 제외한다. 기존 승인된 로컬 CLI fixture와 네이티브 서브에이전트 경로를 유지한다.
- 로컬 서버 통과를 원격 배포·Linux 운영·미설치 제품의 설치 성공으로 표시하지 않는다. 시험 계층과 확인 범위를 따로 기록한다.
- 제품/설정/DB는 격리된 시험 경로를 사용하며 기존 사용자 자료를 변경하지 않는다.

이 결정은 [전체 계획](implementation-plan.md)의 실제 배포·수용 환경을 이번 실행에 맞게 한정한다. 기능·데이터·권한·재처리·근거 보존 계약은 유지한다.
