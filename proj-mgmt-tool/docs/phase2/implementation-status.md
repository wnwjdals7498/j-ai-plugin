## 적용·운영 한계

- 자연어 분해·방법 판단은 메인/역할 스킬이 수행한다. Python은 구조·버전·저장·실행 계약을 처리한다. 스킬 설치만으로 새로운 네이티브 도구가 생기지 않는다.
- 환경의 실제 capability 확인 자료를 등록해야 배정할 수 있다. 제품 버전·임의 모델명·가격만으로 지원이나 최저가를 주장하지 않는다.
- 닫힌 메인 자동 기상·Host 서버·외부 프로젝트 관리툴 동기화는 후속 범위다. 원래 실행의 종료가 불명확하면 자동 대체 실행·점유 회수를 하지 않는다.
- 원격 Claude/API 실제 모델 호출은 사용자 범위 밖이다. Codex의 새 패키지 훅 설치 확인은 남아 있으므로 전체 제품 설치 수용까지 완료했다고 표시하지 않는다.

안전한 실측 요약은 [증거 JSON](evidence/2026-10-01/phase2-status.json), CLI 사용 절차는 [사용법](usage.md)을 참조한다. 숫자·기능 상태를 계획만으로 승격하지 않는다.
