# 구현 중 반영한 범위 결정

2026-10-01 사용자 지시: **직접 API 없이 서브에이전트와 `claude -p`·Codex 명령으로 처리한다.** Claude 검증도 외부 전송 없이 로컬에서 수행한다.

이 결정이 기존 상세계획의 API/SDK 및 OpenCode HTTP runner 제안보다 우선한다. 기존 OpenCode 훅·저장 플러그인은 유지하며 새 실행 경로는 네이티브 서브에이전트와 Claude/Codex CLI에 집중한다.

| 항목 | 현재 구현·검증 범위 |
|---|---|
| 네이티브 서브에이전트 | 메인 실제 도구 호출 → 실행 ID → 결과 저장·검토; 지원 확인·슬롯 부족 대기 |
| 외부 CLI | `claude -p --output-format json`, `codex exec --json`; 설치·인증·모델·권한 확인 |
| 직접 모델 API·SDK·OpenCode HTTP runner | 현재 구현 범위 제외. 해당 요청은 명확히 차단하며 자동 우회하지 않음 |
| Claude 외부 모델 전송 | 사용자 선택으로 미실행; 로컬 제품·응답 fixture 검증과 실제 모델 검증을 구분 |
| 상위/최상위 판단 | 현재 메인 또는 확인된 네이티브 도구에 위임; 필요 문맥·버전·반환 계약 전달 |

인증 키 준비를 요구하지 않는다. CLI가 자체 모델 서비스에 연결하는 것과 PMT가 직접 제공자 API를 호출하는 것을 구별한다. 현재 시험의 로컬 전송 제한을 실제 사용자의 이후 CLI 실행 권한으로 확대 해석하지 않는다.

구현·실측 현황은 [구현 상태](implementation-status.md)에 기록한다. 이전 계획의 시험 목록은 설계 이력이며 제외된 경로를 현재 완료 조건에 넣지 않는다.
