# 1단계 구현·검증 현황

2026-10-01 기준 1단계 구현과 Windows 제품 설치 검증을 완료했다. 아래 결과는 실제 시험 산출물에 연결되어 있다: [안전 요약 JSON](evidence/2026-10-01/native-phase-status.json).

## 구현

- Python 표준 라이브러리와 SQLite로 범위·Work/Item·현재 결정·변경 이력·점유·증거·검증을 저장한다.
- JSON CLI는 요청 재전송, revision 충돌, 원자적 변경, 복구와 명시적 완료를 지원한다.
- 검증 재사용은 scope·환경·작업 공간·입력·기준·증거를 비교하고 실행 전후 지문을 확인한다.
- 제품별 훅은 이벤트와 실패 pending을 보존하며, 지정 프로젝트의 새 세션에 문맥을 전달한다. Stop/idle만으로 완료 처리하지 않는다.
- 독립된 제품별 플러그인 폴더와 ZIP에 파일 hash manifest를 포함한다. 사용자 데이터는 패키지 밖에 둔다.

## 범위

[사용법](../usage.md)에서 패키지 생성·등록, 환경 변수와 CLI 흐름을 확인한다. 모델 선정/분배와 호스팅 서버는 이후 범위다. 자동 GC와 프로젝트 종료/보관 전용 operation도 제공하지 않는다.
